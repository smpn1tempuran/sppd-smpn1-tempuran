Backup & Restore Data SPPD

1. Cadangkan Data (Backup JSON)

Unduh seluruh riwayat SPPD, SPT, database Guru/Siswa, pengaturan pejabat, dan logo ke dalam satu file cadangan di komputer Anda.

2. Pulihkan Data (Restore JSON)

Pilih file backup .json yang pernah Anda unduh sebelumnya untuk memulihkan seluruh data aplikasi.
